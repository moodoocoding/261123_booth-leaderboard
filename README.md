# AI 체험 부스 · 오늘의 랭킹 (TV 화면)

부스 TV나 큰 모니터에 띄워 두는 실시간 리더보드입니다.

- 띄어쓰기 1등은 누구? / 우주정복자 / 구구단 가디언즈(보통 난이도) / 블록 퍼즐 챔피언 / 수학격투 / 휙휙! 로프 스윙 / 비트스매시 클럽 / 택티컬 코어 디펜스 / 나라 수도 맞추기(10문제 도전) / 브레인 대시 / 퀴즈 & 점프 런너의 오늘 순위를 두 줄(여섯 칸씩)로 보여 줍니다. 여덟 칸보다 많으면 칸이 좁아져서 이름과 점수만 보여 주는 촘촘 모드가 됩니다. 칸 높이에 들어가는 만큼(1080p TV에서 6등까지) 보입니다.
- 구구단 가디언즈 순위는 그 게임 서버의 공개 순위 API를 15초마다 읽어 옵니다.
- 새 기록이 들어오면 새로고침 없이 바로 바뀌고 1분 동안 NEW로 표시됩니다.
- 각 게임으로 들어가는 QR 코드가 있습니다.
