# AI 체험 부스 · 오늘의 랭킹 (TV 화면)

부스 TV나 큰 모니터에 띄워 두는 실시간 리더보드입니다.

- 띄어쓰기 1등은 누구? / 우주정복자 / 구구단 가디언즈(보통 난이도) / 블록 퍼즐 챔피언 / 수학격투 / 휙휙! 로프 스윙 / 비트스매시 클럽 / 택티컬 코어 디펜스 / 나라 수도 맞추기(10문제 도전) / 브레인 대시 / 퀴즈 & 점프 런너 / 트리플 퀴즈 쇼 / 부정행위 학생 찾기의 오늘 순위를 두 줄(첫 줄 일곱 칸)로 보여 줍니다.
- 구구단 가디언즈 순위는 공개 순위 API를 15초마다 읽어 옵니다.
- 새 기록이 들어오면 새로고침 없이 바로 바뀌고 1분 동안 NEW로 표시됩니다.
- 오른쪽 위에 **`⛶ 전체 화면`** 전환 버튼(단축키 `F`)과 **`🕹️ 부스 홈으로`** 버튼이 있습니다.
- 오른쪽 아래에는 부스 랭킹 포인트 없이 자유롭게 즐기는 **자유 체험 앱 4종(몽글몽글 그림일기 · 질문 모아 주세요 · 꼬마 기상청장 · 무한의 계단)** 모아보기(`?tab=free`) 링크와 QR 코드가 있습니다.
